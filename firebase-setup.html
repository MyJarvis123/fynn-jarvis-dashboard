Was ist das?
Firebase synchronisiert deine Daten automatisch zwischen Desktop und Handy. Einmal einrichten, dann läuft es!
Schritt 1: Firebase Project erstellen
1. Gehe zu Firebase Console
Öffne console.firebase.google.com
https://console.firebase.google.com
2. Neues Projekt erstellen
Klicke auf "+ Projekt erstellen"
Name: z.B. "JARVIS Dashboard"
Google Analytics: Optional (nicht nötig)
3. Realtime Database aktivieren
Gehe zu "Realtime Database" (im linken Menü)
Klicke "Datenbank erstellen"
Standort: Europe (z.B. europe-west1)
Sicherheitsregeln: Wähle "Im Test-Modus starten"
Schritt 2: Web-App registrieren
1. Project Settings öffnen
Klicke auf das Zahnrad-Icon (oben links)
Wähle "Projekteinstellungen"
2. Web-App hinzufügen
Klicke auf " Web" um eine neue Web-App zu registrieren
App-Name: z.B. "JARVIS"
Klicke "App registrieren"
3. Credentials kopieren
Du siehst einen Code-Block mit firebaseConfig
Kopiere ALLE 6 Werte:
const firebaseConfig = { apiKey: "YOUR_API_KEY", authDomain: "YOUR_AUTH_DOMAIN", databaseURL: "YOUR_DATABASE_URL", projectId: "YOUR_PROJECT_ID", storageBucket: "YOUR_STORAGE_BUCKET", messagingSenderId: "YOUR_MESSAGING_SENDER_ID" };
Schritt 3: Credentials hier eintragen
✓ Firebase ist verbunden!
Deine Daten werden jetzt automatisch synced.

Nutze die App wie gewohnt — auf Desktop und Handy sind deine Daten überall gleich! 🎉
